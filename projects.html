How to install my packs

Works for .mcpack and .mcaddon files on Minecraft Bedrock for Windows and Android.

  1. Download the packGet the .mcpack or .mcaddon file from the project page.
  2. Rename it if neededIf you downloaded a .zip, turn on File name extensions in File Explorer (View, Show), then change the ending to .mcpack (or .mcaddon for an addon).
  3. Open the fileDouble-click it. Minecraft starts and shows “Import started”, then “Successfully imported”.
  4. Activate it in a worldCreate a world or edit an existing one. Open Resource Packs or Behavior Packs, find the pack under My Packs, and select Activate. Addons usually need both.
  5. Turn on experiments if askedIf the project page says it needs experimental features (such as Beta APIs), switch them on in the world settings before you play. Experiments turn off achievements for that world.
Manual install (advanced)

Unzip the pack and copy its folder into development_resource_packs or development_behavior_packs inside the com.mojang folder:

%appdata%\Minecraft Bedrock\Users\Shared\games\com.mojang (current Minecraft for Windows)

%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang (older installs)

  1. Download the packUse your browser to download the .mcpack or .mcaddon file from the project page.
  2. Open it with MinecraftTap the finished download, or find it in your Files app. When Android asks which app to use, choose Minecraft.
  3. Rename it if it won’t openIf you got a .zip, rename it to end in .mcpack (or .mcaddon for an addon) in your Files app, then open it again.
  4. Wait for the importMinecraft shows “Import started”, then “Successfully imported”.
  5. Activate it in a worldCreate a world or edit an existing one. Open Resource Packs or Behavior Packs, find the pack under My Packs, and tap Activate. Addons usually need both.
  6. Turn on experiments if askedIf the project page says it needs experimental features (such as Beta APIs), switch them on in the world settings before you play. Experiments turn off achievements for that world.

Pack not showing up?

  • Check it is activated in your world settings, not only imported.
  • Addons often come as a behavior pack and a resource pack. Activate both.
  • Make sure your Minecraft version matches the one listed on the project.
  • Restart Minecraft and import the file again.
  • Still stuck? Send me a message with your device and Minecraft version.
