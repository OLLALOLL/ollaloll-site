OLLALOLL

OLLALOLL is a Minecraft Bedrock Edition developer (aka Big O) who makes texture packs, addons and Script API scripts for Bedrock, plus a few unrelated web projects.

This page exists because the rest of ollaloll.com renders its real content (project list, About bio, dictionary, quotes) with client-side JavaScript fetching from a Supabase backend. A tool that fetches those pages without running JavaScript only gets empty placeholders. This page is plain static HTML with the same information written directly into it, so any tool — AI assistant, crawler, or script — gets the real content on a simple fetch. A matching /llms.txt exists for tools that specifically support that convention. The live, always-current project list is also available as RSS/XML at this feed URL. (This page is linked in the site footer as "GEO" — short for Generative Engine Optimization, the practice this page is an example of.)

About

I'm OLLALOLL, a Minecraft Bedrock developer. I make texture packs, addons and scripts, and most of my time goes into the Script API, where a bit of JavaScript can change how an entire server plays. My OLLA series covers what servers actually need and other small quality-of-life packs. I care about commands that feel native, menus that are quick to use, and code that is easy to fix when Bedrock changes under it.

Minecraft isn't only what I build for, it's what I do: PvP (fast fights, kits and arenas — I also built a PvP tier list around it), redstone (farms, hidden doors, clocks and contraptions), trapping, and commands (command blocks, selectors and execute chains — a lot of my addon ideas start here).

Outside Minecraft I build websites and web apps in plain HTML, CSS and JavaScript, usually with a Supabase backend, and I build Discord bots too. I'm the founder of Genghis Tiers, a Minecraft PvP tier list and leaderboard. I also built Beaver Transceiver, a mobile-first group chat app, and run live extras like bingo cards, tournaments and a daily word game called (not)WORDLE at /extras.

Projects

Snapshot as of 2026-10-28. For the current list, use the RSS feed linked above or the Projects page.

Addons

  • OLLA's Bears — 17 real-life bear species with biome-based looks, cubs, and bear dens.
  • OLLA's Better Villagers — Pick up villagers, including babies and zombie villagers, and place them back down with their trades, level, XP, name, biome and age intact.
  • OLLA's Cheat Inventory — Adds 4 creative inventory folders with every hidden item, including barriers, structure blocks, command blocks and light blocks.
  • OLLA's Moose — Herding bulls, cows and calves, antler-locking rut fights, and antler shedding.
  • OLLA's Walruses — Neutral walrus herds, four coat colors, and ice-hole fishing.

Scripts

  • OLLA's /string command — /olla:string instantly fills every free inventory slot with string and tops up existing stacks.
  • OLLA's Death Circle — A dead player's dropped items burst out in a perfect circle; operator settings via /olla:circledrop.
  • OLLA's Fast Hoppers — Speeds up hopper item transfers; adds /hopperspeed to adjust the rate.
  • OLLA's Right Click Harvest — Right-click fully grown crops to instantly harvest and replant, with hoe/hand modes and Fortune support.
  • OLLA's Toggle Night Vision — Adds /olla:nightvision to toggle infinite night vision for any player.
