Loot Table Builder

Add items with weights and amounts and get a loot table JSON for your Bedrock behavior pack. It all happens in your browser.

Your loot table

How to use it

  • Weight is the relative chance. An entry with weight 20 is picked twice as often as one with weight 10.
  • Rolls is how many times the game picks from the pool. Use several pools for separate drops.
  • Use Nothing to make a pool sometimes give no item.
  • Use it from a /loot command, a chest, a mob’s drops or fishing: point to loot_tables/…json.
  • The tool checks the format, not whether an item exists. If a typo slips in, Minecraft logs an error and skips it. Custom items use their own namespace, like mypack:ruby.
