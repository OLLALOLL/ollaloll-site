Recipe Builder

Click a 3×3 grid, choose the result and get a recipe JSON for your Bedrock behavior pack. Shaped, shapeless and furnace recipes. It all happens in your browser.

Recipe type

Use the vanilla recipe’s exact ID, like minecraft:diamond_sword. A recipe with the same ID replaces the original. The ID must match exactly, or you’ll just add a second recipe instead.

Good to know

  • Recipes go in a recipes folder in your behavior pack.
  • Use your own namespace in the recipe ID (like mypack:ruby_sword) to add a new recipe. To change a vanilla one, switch on “Replace a vanilla recipe” and use its exact minecraft: ID.
  • Item names can be typed without minecraft:. The tool adds it. Custom items use their own namespace, like mypack:ruby.
  • The tool checks the format, not whether an item exists. If a typo slips in, Minecraft logs an error and skips the recipe.
  • Shaped recipes are trimmed to the smallest box around your items, so a 2×2 recipe stays 2×2.
  • Items with data values (like coloured wool as one item) aren’t supported — use the modern item names (minecraft:red_wool).
